You may share and adapt the data for any purpose, including commercially,
provided you give appropriate credit. Please cite the paper and the archive
DOI (https://doi.org/10.5281/zenodo.22970589); see `CITATION.cff`.

The data are derived, subsampled numeric features computed from publicly
available professional-match demo recordings. No demo files, player names,
SteamIDs or team names are included. Code in this repository is licensed
